Process

How it works

Four steps happen inside a single API call — no manual research, no separate tools to stitch together.

01

Fetch the page

The live website is read and cleaned into plain text — scripts, nav, and footer stripped out.

02

Pull real speed data

Google PageSpeed Insights returns actual mobile performance and SEO scores — not estimates.

03

Run the analysis

An AI model reads the content and speed data together to build the strategic brief.

04

Return structured JSON

One response, seven fields, ready to render in a report, a CRM, or a client dashboard.

Output

EXECUTIVE SUMMARY

One paragraph on how the brand currently positions itself.

TONE OF VOICE

How the brand actually sounds, described in plain language.

USPs

Named competitors, their edge, and how to counter it.

CONTENT GAPS

SEO and content opportunities the brand is missing.

For developers

Call it directly from your own stack

One endpoint, one POST request. Built to be dropped into an agency site, a CRM, or an internal tool.

The endpoint accepts a target URL and an API key, and does the scraping, the speed lookup, and the AI analysis server-side — your app only has to handle the response.

Every call deducts a fixed token amount from the key's balance, returned in the response so usage can be tracked without a separate lookup.

POST /api/analyze Content-Type: application/json CORS enabled 
// Request
fetch("https://brand-dna-api.vercel.app/api/analyze", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    url: "https://prospect-site.com",
    api_key: "YOUR_API_KEY"
  })
});

// Response
{
  "success": true,
  "brand_dna": { ...7 fields },
  "tokens_remaining": 4250
}
